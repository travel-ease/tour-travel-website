# 🌍 TourEase - Tour & Travel Website with Transportation

## 📖 Project Overview
This project is an educational website created for my **college project**.  
The website represents a **Tour & Travel Company** that provides services like tour packages, adventure trips, and transportation facilities.  

The main objective of this project is to demonstrate how **AI tools** (like ChatGPT) can help in creating professional-looking websites using **HTML and CSS**.

---

## 🧰 Tools & Technologies Used
- **HTML5** – For webpage structure  
- **CSS3** – For styling and layout design  
- **AI Assistance** – ChatGPT (for content & code generation)  
- **GitHub Pages** – For free web hosting and publishing  

---

## 🚀 Features
✅ Responsive and professional design  
✅ Attractive homepage with images and cards  
✅ Navigation bar (Home, About, Services, Contact)  
✅ Smooth layout and clean color theme  
✅ Hosted live using GitHub Pages (Free Hosting)

---

## 💡 Learning Outcome
Through this project, I learned:
- How to design a website using HTML & CSS  
- How to use AI tools to speed up website creation  
- How to host a website online using **GitHub Pages**
